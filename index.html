    HyTwin — Technical Documentation¶

    Welcome to the technical documentation for HyTwin, an AI-controlled digital twin of a multi-node hydrogen (H₂) energy network. The flagship scenario is a 7-node Italian network — physics-based component models, virtual sensors with realistic measurement artifacts, an explicit multi-site dispatch layer, reinforcement-learning-based network control, and a real-time "Network Control Room" web dashboard.

    Quick start¶

    # Network Control Room dashboard (recommended)
python -m dashboard --speed-factor 30
# then open http://localhost:8060

# Compare traditional vs. AI control from the CLI
python -c "
from hytwin.simulation.scenario import Scenario
from hytwin.network.compare import compare_controllers
topo = Scenario.from_yaml('config/italy_network_large.yaml').topology()
out = compare_controllers(topo, steps=1008, seed=42,
                           strategies={'none': 'none', 'classical': 'classical'})
for name, kpis in out.items():
    print(name, kpis)
"

# Test suite
pytest tests/ -v

    See 09_usage_guide.md for the full walkthrough, including training an AI agent and running a live Scenario Comparison from the dashboard.
