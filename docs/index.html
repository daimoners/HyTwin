HyTwin

An AI-controlled digital twin of a multi-node hydrogen (H₂) energy network. The flagship scenario is a 7-node Italian network — physics-based component models, virtual sensors with realistic measurement artifacts, an explicit multi-site dispatch layer, reinforcement-learning-based network control, and a real-time "Network Control Room" web dashboard.

What is HyTwin?

HyTwin is a Python framework for simulating, monitoring, and optimising hydrogen-based energy microgrids at network scale. It combines:

  • Physics-based component models — six per-site component models plus two inter-site link models, all with first-principles equations (Butler-Volmer, Faraday's Law, Van der Waals, Betz/Cp curves, NOCT, …)
  • Virtual sensor layer — nine sensor types with noise, drift, delay, quantisation, and fault injection
  • Digital twin state fusion — per-node weighted estimator combining model output and sensor readings, aggregated from TwinNode up through GridTwin (site) to NetworkTwin (multi-site)
  • Network layer — explicit multi-site topology, electric-line and H₂-pipeline links, merit-order dispatch, and network-wide KPIs
  • Gymnasium-compatible RL environments — single-site and a per-node factored network environment for multi-site AI control
  • Network Control Room dashboard — a 9-screen FastAPI + WebSocket web UI for running, monitoring, training, and comparing controllers live

Quick Start

# Network Control Room dashboard (recommended)
python -m dashboard --speed-factor 30
# then open http://localhost:8060

# Compare traditional vs. AI control from the CLI
python -c "
from hytwin.simulation.scenario import Scenario
from hytwin.network.compare import compare_controllers
topo = Scenario.from_yaml('config/italy_network_large.yaml').topology()
out = compare_controllers(topo, steps=1008, seed=42,
                           strategies={'none': 'none', 'classical': 'classical'})
for name, kpis in out.items():
    print(name, kpis)
"

# Test suite
pytest tests/ -v

See Chapter 9 · Usage Guide for the full walkthrough, including training an AI agent and running a live Scenario Comparison from the dashboard.
