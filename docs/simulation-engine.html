CHAPTER 7

Dashboard — Network Control Room

The 9-screen FastAPI + WebSocket real-time web dashboard — the primary, recommended way to run, monitor, and control the full multi-site network simulation from a browser.

7.1 Overview

dashboard/network_app.py serves a FastAPI + WebSocket real-time web dashboard — the "Network Control Room" — that runs, monitors, and controls the full multi-site network simulation from a browser. It is the primary, recommended way to operate HyTwin.
